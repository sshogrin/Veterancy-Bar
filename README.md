This is an ESO addon that displays the Veterancy progress in a bar that is moveable.
You can change the color of the background and progress bar itself.
The main part of the addon is created by Noxenrom, I've added the settings panel and settings functions.
At some point, there will be a "Lock" function to lock the progress bar on screen through the Settings panel in game.
LibAddonMenu2 is required for this addon.
